# COLE Platform 环境组到数据组交付说明

## 交付范围

本包只包含环境组负责的内容：

- `TrajectoryRecorderV2` 非侵入式环境包装器；
- `trajectory_schema_v2` 及校验器；
- 五类基于前后真实状态变化的任务事件检测；
- 程序化策略动作适配器；
- 单局真实环境运行入口；
- 轨迹离线校验、原始 MDP 重放和环境组总验收脚本；
- 真实环境样例、事件审计集、manifest schema 和验证报告。

本包不包含 COLE 权重，不修改或运行 COLE 策略、模型和训练代码，也不包含网页端改动。

## 放置方式

将压缩包解压到 COLE-Platform 项目根目录，使 `overcookedgym` 和
`platform_data_handoff_v2` 与项目中的同名目录合并。建议先在独立副本中验收。

推荐使用已有 Conda 环境：

```powershell
conda activate cole-platform
```

若未激活环境，以下命令中的 `python` 可替换为：

```powershell
conda run -n cole-platform python
```

## 一条命令总验收

在项目根目录执行：

```powershell
python -B overcookedgym\scripts\verify_environment_handoff.py
```

预期关键输出：

```text
environment handoff validation: PASS
checks=4
event_audit_rows=50
No COLE model was loaded and no training was run.
```

机器可读报告位于：

```text
platform_data_handoff_v2/logs/environment_handoff_validation.json
```

## 生成一条最小真实环境轨迹

```powershell
python -B overcookedgym\scripts\run_single_episode.py `
  --layout-id simple `
  --seed 7 `
  --human-index 0 `
  --ego-agent-idx 0 `
  --episode-id receiver-smoke-001 `
  --horizon 10 `
  --human-constant 4 `
  --cole-constant 4 `
  --output-dir receiver_output
```

自动实验中的 `human_action` 表示 focal player policy 的动作，不代表真人数据。
controller 当前关闭，因此每一步应满足 `final_ai_action == cole_action`。

## 验证轨迹

```powershell
python -B overcookedgym\scripts\validate_raw_trajectory.py receiver_output\receiver-smoke-001.trajectory.jsonl
```

## 重放轨迹

```powershell
python -B overcookedgym\scripts\replay_episode.py receiver_output\receiver-smoke-001.trajectory.jsonl
```

重放脚本使用项目原始 MDP 状态转移和 reward 逻辑，逐步核对下一状态及团队奖励。

## 动作编号

| 编号 | 动作 |
|---:|---|
| 0 | up |
| 1 | down |
| 2 | right |
| 3 | left |
| 4 | stay |
| 5 | interact |

编号来自原项目 `actions.py`，环境组没有修改映射。

## 事件类型

- `ingredient_acquired`
- `ingredient_put_in_pot`
- `plate_acquired`
- `soup_plated`
- `soup_delivered`

事件检测只比较 `state_before/state_after` 和必要的环境结果证据，不依据 action 猜测意图。
`event_audit.jsonl` 每类包含 5 个正例、5 个相邻负例，且每类至少一个正例来自真实
`OvercookedMultiEnv`。

## 异常对局

单局运行失败或程序化脚本耗尽时，manifest 使用：

```json
{
  "status": "invalid_episode",
  "termination_reason": "具体原因"
}
```

异常对局不得静默删除或作为有效训练轨迹使用。

## 已知限制

1. 当前项目副本没有 `.git` 元数据，因此无法提供权威 commit SHA；`repo_commit.txt`
   已记录这一情况。
2. 当前没有官方冻结 COLE checkpoint；`checkpoint_inventory.json` 明确标记
   `BLOCKED_MISSING_INPUT`。这不影响环境、轨迹和事件接口验收，但冻结 COLE 推理必须由
   获得权重的联调组另行验证。
3. 本包没有批量正式数据生产入口；环境组仅交付经验证的单局接口和样例，不替数据组选择
   Agent、确定数据规模或生产正式训练数据。

- 当前工作目录；
- 对应 manifest 和 trajectory（如已生成）；
- `platform_data_handoff_v2/logs/environment_handoff_validation.json`。
